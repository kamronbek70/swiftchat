Firebase Setup

1-qadam — Firebase proyekt
console.firebase.google.com ga kiring → Add project → nom kiriting → proyekt yarating
2-qadam — Realtime Database
Chap menyu → Realtime Database → Create database → test mode tanlang → Enable bosing
3-qadam — Database URL
Database sahifasida URL ko'rinadi:
https://your-project-default-rtdb.firebaseio.com
Shu URL ni quyidagi maydonga joylashtiring:
URL noto'g'ri yoki bo'sh. Firebase URL kiritng.
